实时试听引擎：使用 Web Audio 的专用音频渲染线程（原生 AudioBufferSourceNode 无缝循环 + AnalyserNode 频谱显示），循环播放全部发生在浏览器原生音频管线里，主线程没有逐样本负担，改参数即时生效。页面切后台 / 锁屏时它可能被系统挂起。

睡眠模式引擎：把当前混音渲染为整段音频，用 Web Audio 的 AudioBufferSourceNode 做样本级无缝循环（原生 <audio loop> 在多数浏览器会在循环点产生约 20–80ms 的缝隙，故不再作为主路径）。同时用一个隐藏的 <audio> 媒体元素播放整段音频，并经 Web Audio 以 0 增益接入（静音）——它只负责注册系统媒体会话，让锁屏 / 系统播放控件正常出现，并让浏览器把该标签视为「正在播放」，减少后台被冻结或回收。若系统仍挂起 Web Audio，会自动回退到原生 <audio loop>（可出声，但循环点会有缝隙）。实时试听期间切后台，页面会自动切换到该引擎。但仍建议需要整夜播放时直接使用睡眠模式启动，以防止兼容性问题引起的错误或不可靠的后台播放。

整夜使用与权限指南

  • 首次使用：所有播放都从你的点击开始（浏览器要求用户手势才允许发声）。第一次点击播放按钮时，页面会同时解锁音频权限，之后锁屏播放不再需要任何确认。
  • 整夜播放的正确姿势：点击「🌙 进入睡眠模式」，确认出声后直接锁屏即可。请勿在多任务里上滑划掉该页面（那会终止音频）。锁屏界面 / 通知栏可随时暂停或恢复。
  • 屏幕唤醒锁（Wake Lock）：亮屏状态下会自动申请，防止看着屏幕时自动熄屏；部分浏览器或隐私模式会拒绝（不影响睡眠模式——熄屏才是最省电的状态）。页面重新可见时会自动重新申请。
  • 耗电建议：优先「睡眠模式 + 熄屏」；采样率选 22050 Hz；音量尽量低（配合物理音量键）；手机建议插电过夜。连接外部蓝牙音箱也是不错的选择。
  • 听不到声音？检查系统媒体音量；iPhone 检查静音拨片；部分安卓机型需在系统设置中允许该浏览器「后台运行」。
  • 睡眠定时：到时会淡出并停止。注意 iOS 在熄屏后可能冻结页面计时器，定时停止可能延迟到点亮屏幕时执行——若要整夜播放保持「关闭」即可，这正是默认值。
  • 导出 WAV：把当前混音导出为音频文件，可放进本地播放器离线整夜循环（彻底不受浏览器限制）。

02功率谱设计 / 查看器

当前查看的是：—

· 功率谱与随机过程原理 / 采样率与循环长度（点开查看）

新建的自定义预设可编辑，所有内置预设都不可编辑（因为其中一些随机过程甚至不是靠指定功率谱能实现的），此处显示其实时频谱；自定义预设可拖动圆点编辑平滑功率谱曲线。

把噪声视为广义平稳随机过程：定义功率谱密度 S(f)（纵轴相对 dB、横轴对数频率），为每个频率分量赋予独立随机相位，经逆傅里叶变换得到具有该功率谱的（近似高斯）随机过程样本，天然周期无缝、可无限循环。拖动圆点编辑，双击圆点删除。

采样率决定可合成的频率上限（奈奎斯特频率 = 采样率 / 2），降低采样率可减少数据量与耗电；循环越长，低频起伏越接近真实随机过程，但渲染耗时与内存略增。
